# Reevan Shop

This repository contains the source code for the REVAAN luxury South Asian fashion storefront. The application is built with Vite, React, TypeScript, and Tailwind CSS.

## Project info

Use the instructions below to work locally.

## How can I edit this code?

There are several ways to edit the application:

**Use your preferred IDE**

Clone the repository and work locally:

```sh
git clone <YOUR_GIT_URL>
cd <YOUR_PROJECT_NAME>
npm install
npm run dev
```

All changes are committed via Git as usual.

## Technologies

This project uses:

- Vite
- React
- TypeScript
- shadcn-ui
- Tailwind CSS

## Deployment

Build for production with:

```sh
npm run build
```

and then deploy the `dist` folder to your hosting provider.
